# PetroAnalysis Studio

Desktop well-log analysis workspace organized as a standard `src/` Python project.

## Layout

- `src/petroanalysis/`: application package
- `scripts/run_app.py`: local launcher
- `integrate.py`: compatibility launcher
- `data/samples/`: sample LAS and DLIS files
- `tools/`: standalone utilities
- `archive/experimental/`: non-runtime prototypes

## Run

```bash
python scripts/run_app.py
```
