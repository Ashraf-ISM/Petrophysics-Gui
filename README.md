## ✨ Features
- 📂 Import **well log data** (CSV, LAS)  
- 📊 Perform basic petrophysical calculations:
  - Effective Porosity (Φe)  
  - Shale Volume (Vsh)  
  - Water Saturation (Sw, Archie’s Equation)  
- 🎨 **Interactive GUI** with PyQt5  
- 📈 Multi-track log plots and crossplots  
- ⚡ Parameter tuning via sliders (future feature)  
- 💾 Export results to CSV
